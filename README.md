# 专项职业能力考核在线报名系统

校内网在线报名系统，默认端口 `8018`。

## 入口

- 学生报名入口：http://127.0.0.1:8018/reg
- 学生报名操作指南：http://127.0.0.1:8018/reg/guide
- 系统管理员后台：http://127.0.0.1:8018/xxgcxy
- 班级管理员后台：http://127.0.0.1:8018/classadmin

默认系统管理员：

```text
账号：admin
密码：admin
```

## 功能

- 学生第一次填写报名信息时自动登记账号。
- 保存草稿会生成 6 位查询密码，后续用 `身份证号 + 查询密码` 查询或修改。
- 忘记查询密码时，可在学生查询页面或班级管理员登录页面通过 `身份证号 + 报名手机号` 生成新的 6 位查询密码。
- 学生和后台列表提供“报名材料体检卡”，自动判断字段、照片、提交和审核是否达到正式导出条件。
- 管理员可手动开启/关闭报名入口；关闭后学生只能查询不能修改。
- 照片严格校验：JPG、90px × 110px、≤20KB。
- 报考科目三选一，报名费固定 130 元。
- 正式提交时进行后端名额限制：CAD 中级 + 高级合计 320 人，Protel 160 人；草稿不占用名额。
- 系统管理员可管理班级、导入班级、管理考生、审核报名、赋予班级管理员权限、导出审核通过数据。
- 班级管理员只能管理绑定班级，可标记缴费和导出本班材料。

## 安装和初始化

需要 Node.js 20+。当前项目已按 Node.js 24 测试。

```bash
npm install
npm run init
```

初始化会创建 SQLite 数据库并写入默认管理员账号。正式部署前请在本地 `.env` 中配置不公开的管理员密码，例如：

```text
ADMIN_USERNAME="admin"
ADMIN_PASSWORD="请改为私密强密码"
```

## 开发启动

```bash
npm run dev
```

或双击：

```text
scripts/start-dev.bat
```

## 生产启动

```bash
npm run build
npm run start
```

或双击：

```text
scripts/start-prod.bat
```

如果页面打开后只有浏览器默认样式，通常是旧的 `8018` 服务进程还在运行、但 `.next` 构建产物已经更新。重新运行上述启动脚本会先停止旧进程再启动新服务；也可以手动运行 `scripts/stop-port-8018.ps1` 后再执行 `npm run build && npm run start`。

如果通过 `http://服务器IP:8018/xxgcxy/login` 登录后仍停留在登录页，请确认 `.env` 中没有把 `AUTH_COOKIE_SECURE` 设置为 `true`。只有在 HTTPS 部署时才应开启 Secure Cookie；内网 HTTP 访问应保持为 `false` 或不设置。

服务默认监听 `0.0.0.0:8018`，内网其他电脑访问：

```text
http://服务器IP:8018/reg
```

## 班级导入

管理员后台进入“班级管理”，可以手动新增班级，也可以导入 `.xlsx`。

推荐使用“从附件/学籍信息一键生成班级”：系统会读取本地 `附件/学籍信息/` 下所有 `.xlsx` 文件的“院系 / 所在年级 / 班级”列，生成学生端三级选择列表，例如：`信息工程学院-2025-移动互联2531`。

如果手动上传 Excel，系统同样会优先识别表头“院系 / 所在年级 / 班级”；没有这些表头时，读取第一列作为班级名称。

## 模板文件

附件文件不随代码仓库发布。部署时请在本地建立 `附件/` 目录，并放入以下模板：

- `附件/附件二.考生导入模板.xlsx`：考生导入模板导出。
- `附件/附件三.缴费报名表.xlsx`：缴费报名表导出。
- `附件/附件一.福建省专项职业能力考核申报表.doc`：作为申报表参考；系统导出仿版 HTML 申报表。

## 导出说明

管理员和班级管理员均可导出：

- 考生导入模板 `.xlsx`
- 缴费报名表 `.xlsx`
- 电子照片包 `.zip`
- 申报表包 `.zip`
- 总包 `.zip`

所有正式材料导出仅包含“已提交且审核通过”的考生，草稿、待审核和审核不通过记录不会进入导出文件。电子照片包中的照片文件名使用考生身份证号，例如 `350481198808021012.jpg`。

考生导入模板会自动补全固定字段：

- 证件类型：居民身份证
- 考生来源：院校学生-普通大专
- 职业年限：0
- 文化程度：大专
- 鉴定分类：初次鉴定
- 报考城市：福建省/三明市

## 备份

手动备份：

```text
scripts/backup.bat
```

也可直接运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/backup.ps1
```

备份内容包括：

- SQLite 数据库
- 上传照片和生成文件
- `.env`
- 附件模板

安装每天 12:00 和 00:00 的 Windows 计划任务：

```text
scripts/install-backup-task.bat
```

取消计划任务：

```text
scripts/uninstall-backup-task.bat
```

## 安全措施

- 使用 Prisma 参数化查询，避免 SQL 注入。
- 密码和查询密码使用 bcrypt 哈希保存。
- 后端接口按角色鉴权，班级管理员接口强制限制本班 `classId`。
- 学生只能通过当前登录会话访问自己的报名信息。
- 上传照片校验扩展名、MIME、真实 JPEG 格式、尺寸和大小。
- 上传文件按身份证号重命名，不使用用户原始文件名。
- 导出和下载接口均需鉴权，不直接暴露 `storage` 目录。
- 用户输入使用 Zod 校验，身份证号严格校验 18 位大陆居民身份证。

## 数据位置

- 数据库：`prisma/dev.db`
- 照片：`storage/photos/`
- 导出临时目录：`storage/exports/`
- 备份：`backups/`

## 后续建议

首次正式部署前，建议修改 `.env` 中的 `AUTH_SECRET` 为一串长随机字符串，并在管理员后台创建班级后再开放学生报名。
